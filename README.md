**#Employee Payroll App**

**##Overview**

Employee Payroll App is a Java console application designed to demonstrate Object-Orientde Programming (OOP) concepts through a real-world payroll management system.
The project focuses on applying core OOP principles such as encapsulation, inheritance, ploymorphism, abstraction, and composition while solving common enterprise payroll operations.

**##System Goals**
- Employee registration with validation
- Secure authentication and login
- Monthly payslip generation
- payslip download and printing
- Dashboard analytics
- Centralized input validation
